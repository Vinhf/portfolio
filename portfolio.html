Sell Course Platform

Personal project — course marketplace with an AI quiz generator

A full e-learning marketplace with three moving parts: a student app for browsing and taking courses, an admin dashboard for running them, and a separate AI service that turns an uploaded document into a quiz.

Frontend (Next.js) — course browsing, learning, quizzes, profile Admin Dashboard (Next.js) — users, courses, analytics, content Backend API (NestJS) — auth, enrollment, PayOS payments, quizzes, support chat over WebSocket, certificates AI Quiz Generator (FastAPI) — Google Gemini, reads DOCX/JSON, writes quizzes automatically Data — PostgreSQL + Redis, files on Azure Storage
  • Payments & enrollment: wired a PayOS checkout flow directly to enrollment status, so course access unlocks as soon as a payment confirms.
  • Realtime support: built a WebSocket chat channel between students and course admins for live Q&A during a course.
  • AI quiz pipeline: a separate FastAPI service reads an uploaded DOCX/JSON outline and calls Google Gemini to draft a ready-to-review quiz.
  • Certificates: generated a completion certificate automatically once a student finishes a course.

E-Learning System with an AI Automation Agent

Team project, 5 people — May 2025 to Aug 2025

Built to take one job off a support team's plate: reading incoming student questions, working out what they actually need, and routing them automatically.

  • Backend: REST APIs on NestJS and PostgreSQL, with JWT auth and role-based permissions.
  • Frontend: built the inquiry and ticket views in Next.js with shadcn/ui, kept in sync with the team's NestJS APIs.
  • Testing: covered both normal and edge-case requests in Postman before release.
  • Docs: wrote the API reference and setup guide the rest of the team used.
